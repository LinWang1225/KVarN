Take derivative: f’(x) = [ (1/2)*2 / sqrt(2(1 + x)) ] + 2 = [1 / sqrt(2(1 + x))] + 2. Since sqrt(2(1 + x)) is positive, the derivative is always positive in this interval. Therefore, the function is increasing on [1/2, 1], so maximum at x = 1: f(1) = sqrt(2*2) + 2*1 - 1 = sqrt(4) + 1 = 2 + 1 = 3.
